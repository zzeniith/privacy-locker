`Privacy Locker` is a lightweight, secure, and privacy-focused application designed to protect sensitive files, folders, or application data from unauthorized access. Built with zero-tracking principles, it ensures your private information stays strictly on your local machine.

---

## ✨ Features

- **Local Encryption:** Uses military-grade encryption (e.g., AES-256) to lock files completely offline.
- **Zero Permissions:** No telemetry, tracking, or unnecessary network access required.
- **User-Friendly Interface:** Simple and intuitive workflow to secure and retrieve files instantly.
- **Lightweight & Fast:** Minimal resource footprint with lightning-fast execution.
